# Hi, I’m Carry Lewis

**中文** · [English](README.en.md)

**学习医学，也通过构建工具检验自己的理解。**

我是一名医学生，关注医学学习、人工智能与个人知识管理。遇到一个难以理解的机制，或一件反复费时的工作，我会尝试把它做成可以操作、观察和改进的软件。

## 我在构建什么

### [ECG Simulator](https://github.com/CarryLewis/ECG-stimulator)

从心脏解剖和电传导出发，探索怎样让医学机制变得可以观察、可以理解。目前主分支提供心脏解剖与传导可视化，十二导联描记等功能仍在独立分支中演进。

### [Labwise](https://github.com/CarryLewis/lab-report-assistant)

面向教师的实验报告辅助评阅工作台：把原文、评分标准与 AI 建议放在一起，让反馈有据可查，让最终判断由教师掌握。目前处于本地试点与持续开发阶段。

### [Personal Knowledge Bridge](https://github.com/CarryLewis/personal-knowledge-bridge)

把日常问题、读书材料和自己的思考联系起来。目前支持从 Notion 单向同步到本地 Obsidian，方便沿着笔记之间的链接重新阅读。

## 我持续关心的问题

- 怎样让医学学习从记住结果，走向理解机制？
- AI 怎样帮助人理解材料、形成判断？
- 零散的阅读与经历，怎样逐渐成为可以回访的知识？

软件之外，我也通过长跑、阅读与信仰思考人的限制与长期投入。
